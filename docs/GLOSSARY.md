# 术语表

本术语表用于产品文案、类型名称、数据库字段和测试描述。实现中不得使用多个近义词表达同一个领域概念。

## 核心术语

| 中文术语 | 建议代码名 | 定义 |
| --- | --- | --- |
| 公司 | `Company` | 招聘主体。公司本身不代表一次投递，可关联多个岗位申请和招聘会。 |
| 岗位申请 | `Application` | “公司 + 岗位 + 招聘批次”组成的一次独立求职尝试，是产品主线。界面简称“申请”。 |
| 招聘批次 | `RecruitmentCycle` / `cycleLabel` | 如 2027 届秋招、提前批、补录或某次重新投递，用于区分同公司同岗位的多次申请。 |
| 主阶段 | `ApplicationStage` | 跨公司统一的粗粒度进度：机会池、准备投递、已投递、测评/笔试、面试中、Offer、归档。 |
| 归档原因 | `ArchiveReason` | 申请结束的原因：拒绝、放弃、撤回或其他。Offer 不自动等于归档。 |
| 下一步行动 | `NextAction` | 一条活跃申请当前最重要、唯一突出显示的行动，可带截止时间。它不是通用多任务清单。 |
| 等待状态 | `WaitingState` | 暂无可执行行动时的显式状态，必须关联一条承载复查日期/时刻的复查事件；等待对象 `waiting_for` 与说明可选。 |
| 待补状态 | `NeedsAction` | 活跃申请尚无下一步且未进入有效等待时的显式风险状态，可来自快速创建、不完整导入/迁移、明确稍后补充或归档恢复，必须出现在“今日 > 缺少下一步”。 |
| 事件 | `Event` | 有时间意义的安排或截止点，如面试、笔试、招聘会、投递截止、跟进日期；定时事件开始必填，结束可选，无结束表示时间点。 |
| 面试轮次 | `InterviewRound` | 申请下可重复出现的面试节点，可自由命名并关联事件、结果和复盘。 |
| 招聘会 | `RecruitmentFair` | 独立活动，可关联多个公司、目标岗位、申请、现场笔记和会后行动。 |
| 招聘会目标现场状态 | `RecruitmentFairTargetOnsiteStatus` | `NOT_CONTACTED` 未接触、`CONTACTED` 已接触、`FOLLOW_UP_NEEDED` 需跟进、`NOT_INTERESTED` 不再考虑。 |
| 资料 | `Material` | 与公司、申请或面试轮次关联的内容，分为 JD 快照、外部资料和个人记录。 |
| JD 快照 | `JobDescriptionSnapshot` | 创建或更新时保存的岗位描述文本副本；正文必填，避免原网页变化或失效。 |
| 外部资料 | `ExternalResource` | 外部面经、岗位页面或其他资料；标题必填，且来源 URL 与正文至少有一项。 |
| 个人面试记录 | `InterviewNote` | 针对具体面试轮次的准备、问题、回答和复盘；正文与轮次关联均必填，默认敏感且不共享。 |
| 附件 | `Attachment` | 只能直接归属于资料的图片或 PDF；轮次附件通过该轮次的 `InterviewNote` 间接关联，数据库只保存元数据和对象键。 |
| 时间线条目 | `TimelineEntry` | 阶段变化、事件结果、下一步变化等事实记录，用于追溯而不是聊天消息。 |
| 分享卡片 | `ShareExport` | 从明确选择的字段生成、经过脱敏预览的本地 HTML/Markdown 文件。 |
| 编辑器恢复草稿 | `EditorRecoveryDraft` | M1 起保存在固定 origin IndexedDB，仅保护长文本尚未成功保存的内容；不是正式数据，不进入完整备份，也不代表支持离线创建。 |
| 断连快速草稿 | `OfflineCaptureDraft` | M3 起在本地服务断连时保存到固定 origin IndexedDB 的快速创建输入；重连后确认写入，不属于正式数据且不进入完整备份。 |
| SQLite 捕获草稿 | `CaptureDraft` | 已保存到当前本地数据 generation、尚未确认写入正式实体的粘贴或 AI 提取结果，可进入完整备份。 |

## 阶段定义

| 阶段 | 含义 | 典型进入条件 |
| --- | --- | --- |
| 机会池 | 已发现且可能考虑的岗位 | 保存岗位或招聘会目标，但尚未开始准备 |
| 准备投递 | 正在准备材料或等待开放 | 用户主动推进，尚未提交 |
| 已投递 | 已提交申请，等待后续 | 用户确认完成投递 |
| 测评/笔试 | 已收到或正在进行测评、笔试 | 创建相关流程节点或用户手动修改 |
| 面试中 | 已进入至少一轮面试流程 | 用户手动确认；事件结束不能自动推进 |
| Offer | 已收到录用意向或正式 Offer | 用户手动确认 |
| 归档 | 不再需要出现在活跃看板 | 用户选择归档原因并确认 |

## 文案约定

- 使用“申请”，不使用“项目”“机会记录”混指岗位申请。
- 使用“阶段”表示主流程位置；使用“结果”表示某次面试或事件的结果。
- 使用“截止时间”表示硬期限；使用“复查日期”表示等待后的主动检查点。
- “删除”进入回收站；“永久删除”才表示不可恢复操作。
- AI 结果始终称为“草稿”或“建议”，不得暗示已经自动写入。
